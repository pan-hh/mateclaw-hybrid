# 混合检索架构实现方案

## 一、整体架构设计

### 1.1 架构概述

本方案基于 Java SPI 扩展机制，实现 **Elasticsearch 全文索引 + Milvus 向量检索** 的混合检索双知识库架构。通过异步向量化存储与余弦相似度语义检索能力，结合多租户索引隔离策略与异常降级机制，显著增强 Agent 长期记忆与 RAG 场景下的知识检索能力。

### 1.2 架构层次

```
┌─────────────────────────────────────────────────────────────────────┐
│                        Agent Layer                                  │
│  ┌─────────────┐  ┌──────────────────┐  ┌───────────────────────┐   │

                                │

│  │   Elasticsearch Full-Text   │  │  Milvus Vector Search       │   │
│  │   (全文索引)                │  │  (向量数据库)               │   │
```

### 1.3 核心组件职责

| 组件 | 职责 | 状态 |
|------|------|------|
| **HybridStoreProvider** | SPI 接口定义，抽象向量存储能力 | 新增 |
| **MilvusHybridStoreProvider** | Milvus 向量检索实现 | 新增 |
| **ElasticsearchProvider** | Elasticsearch 全文检索实现 | 新增 |
| **FallbackHybridStoreProvider** | 降级实现，失败时回退 MySQL | 新增 |
| **HybridStoreManager** | SPI 加载与分发，管理多租户隔离 | 新增 |
| **KnowledgeRetrievalTool** | MCP 工具封装，供 Agent 调用 | 新增 |
| **HybridRetriever** | 融合 ES + Milvus 双检索 | 新增 |
| **MilvusAsyncEmbeddingService** | 异步向量化存储服务 | 新增 |
| **ElasticsearchSyncService** | 文档同步到 ES 服务 | 新增 |

### 1.4 技术选型对比

| 维度 | Elasticsearch | MySQL | Milvus |
|------|--------------|-------|--------|
| **检索类型** | 全文检索（BM25） | LIKE 匹配 | 混合检索（余弦相似度） |
| **复杂度** | O(log n) | O(n) | O(log n) |
| **分词支持** | IK 分词器 | 无 | 无（需外部向量化） |
| **相关性评分** | BM25 | 简单匹配 | 余弦相似度 |
| **分布式扩展** | ✅ | ❌ | ✅ |
| **适用场景** | 关键词全文检索 | 元数据管理 | 语义相似度检索 |

### 1.5 Embedding 模型选型

**最终选择：DashScope text-embedding-v3（1024 维）**

**选择理由**：
1. **零接入成本**——项目已内置该模型
2. **维度对齐**——同一 1024 维向量空间，ES 与 Milvus 结果可融合排序
3. **中文质量**——DashScope 在中文语义任务上表现优秀

```java
package vip.mate.hybrid.spi;

import java.util.List;
import java.util.concurrent.CompletableFuture;

public interface HybridStoreProvider {

    String id();

    default int order() {
        return 100;
    }

    boolean isAvailable();

    CompletableFuture<WriteResult> writeAsync(Long workspaceId, List<VectorDocument> documents);

    CompletableFuture<RetrievalResult> retrieveAsync(Long workspaceId, String query, int topK);

    CompletableFuture<Void> deleteAsync(Long workspaceId, List<String> documentIds);

    CompletableFuture<Void> clearAsync(Long workspaceId);

    CompletableFuture<VectorStats> getStatsAsync(Long workspaceId);

    record VectorDocument(String id, String content, float[] embedding, 
                          java.util.Map<String, Object> metadata) {}

    record RetrievalHit(String id, String content, float score, 
                        java.util.Map<String, Object> metadata) {}

    record WriteResult(int successCount, int failedCount, List<String> failedIds) {}

    record RetrievalResult(List<RetrievalHit> hits, boolean fallbackUsed, String errorMessage) {}

    record VectorStats(long totalVectors, int dimension, String indexType) {}
}
```

### 3.2 Elasticsearch 提供者实现

```java
// 文件: src/main/java/vip/mate/hybrid/provider/ElasticsearchProvider.java
package vip.mate.hybrid.provider;

import co.elastic.clients.elasticsearch.ElasticsearchClient;
import co.elastic.clients.elasticsearch._types.query_dsl.MatchQuery;
import co.elastic.clients.elasticsearch._types.query_dsl.MultiMatchQuery;
import co.elastic.clients.elasticsearch._types.query_dsl.Query;
import co.elastic.clients.elasticsearch.core.IndexRequest;
import co.elastic.clients.elasticsearch.core.SearchRequest;
import co.elastic.clients.elasticsearch.core.SearchResponse;
import co.elastic.clients.elasticsearch.core.search.Hit;
import jakarta.annotation.PostConstruct;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;
import vip.mate.hybrid.config.ElasticsearchProperties;
import vip.mate.hybrid.spi.HybridStoreProvider;

import java.util.*;
import java.util.concurrent.CompletableFuture;

@Slf4j
@Component
@RequiredArgsConstructor
public class ElasticsearchProvider implements HybridStoreProvider {

    private final ElasticsearchProperties properties;
    private ElasticsearchClient client;

    @PostConstruct
    void init() {
        if (!properties.isEnabled()) {
            log.info("[ES] Elasticsearch is disabled");
            return;
        }
        try {
            // 构建 ES 客户端
            client = new co.elastic.clients.elasticsearch.ElasticsearchClient(
                    new co.elastic.clients.json.jackson.JacksonJsonpMapper(),
                    new co.elastic.clients.transport.rest_client.RestClientTransport(
                            org.elasticsearch.client.RestClient.builder(
                                    new org.apache.http.HttpHost(properties.getHost(), properties.getPort(), properties.getScheme())
                            ).build(),
                            new co.elastic.clients.json.jackson.JacksonJsonpMapper()
                    )
            );
            log.info("[ES] Connected to Elasticsearch: {}:{}", properties.getHost(), properties.getPort());
        } catch (Exception e) {
            log.error("[ES] Failed to connect to Elasticsearch: {}", e.getMessage());
            client = null;
        }
    }

    @Override
    public String id() {
        return "elasticsearch";
    }

    @Override
    public int order() {
        return 20;
    }

    @Override
    public boolean isAvailable() {
        return properties.isEnabled() && client != null;
    }

    @Override
    public CompletableFuture<WriteResult> writeAsync(Long workspaceId, List<VectorDocument> documents) {
        return CompletableFuture.supplyAsync(() -> {
            if (!isAvailable()) {
                return new WriteResult(0, documents.size(), documents.stream()
                        .map(VectorDocument::id).toList());
            }
            
            String indexName = buildIndexName(workspaceId);
            ensureIndexExists(indexName);
            
            int successCount = 0;
            List<String> failedIds = new ArrayList<>();
            
            for (VectorDocument doc : documents) {
                try {
                    Map<String, Object> source = new HashMap<>();
                    source.put("id", doc.id());
                    source.put("content", doc.content());
                    source.put("metadata", doc.metadata());
                    
                    IndexRequest<Map<String, Object>> request = IndexRequest.of(i -> i
                            .index(indexName)
                            .id(doc.id())
                            .document(source)
                    );
                    
                    client.index(request);
                    successCount++;
                } catch (Exception e) {
                    log.error("[ES] Index failed for doc {}: {}", doc.id(), e.getMessage());
                    failedIds.add(doc.id());
                }
            }
            
            return new WriteResult(successCount, failedIds.size(), failedIds);
        });
    }

    @Override
    public CompletableFuture<RetrievalResult> retrieveAsync(Long workspaceId, String query, int topK) {
        return CompletableFuture.supplyAsync(() -> {
            if (!isAvailable()) {
                return new RetrievalResult(Collections.emptyList(), false, "ES not available");
            }
            
            String indexName = buildIndexName(workspaceId);
            
            try {
                Query queryBuilder = MultiMatchQuery.of(m -> m
                        .query(query)
                        .fields("content^3", "title^2", "summary")
                        .fuzziness("AUTO")
                )._toQuery();
                
                SearchRequest request = SearchRequest.of(s -> s
                        .index(indexName)
                        .query(queryBuilder)
                        .size(topK)
                );
                
                SearchResponse<Map> response = client.search(request, Map.class);
                
                List<RetrievalHit> hits = new ArrayList<>();
                for (Hit<Map> hit : response.hits().hits()) {
                    hits.add(new RetrievalHit(
                            hit.id(),
                            hit.source().get("content").toString(),
                            hit.score() != null ? hit.score().floatValue() : 0f,
                            (Map<String, Object>) hit.source().get("metadata")
                    ));
                }
                
                return new RetrievalResult(hits, false, null);
                
            } catch (Exception e) {
                log.error("[ES] Search failed: {}", e.getMessage());
                return new RetrievalResult(Collections.emptyList(), false, e.getMessage());
            }
        });
    }

    private String buildIndexName(Long workspaceId) {
        return properties.getIndexPrefix() + "_" + workspaceId;
    }

    private void ensureIndexExists(String indexName) {
        try {
            boolean exists = client.indices().exists(e -> e.index(indexName)).value();
            if (!exists) {
                client.indices().create(c -> c.index(indexName).mappings(m -> m
                        .properties("content", p -> p.text(t -> t.analyzer("ik_max_word")))
                        .properties("title", p -> p.text(t -> t.analyzer("ik_max_word")))
                        .properties("summary", p -> p.text(t -> t.analyzer("ik_max_word")))
                ));
                log.info("[ES] Created index: {}", indexName);
            }
        } catch (Exception e) {
            log.error("[ES] Failed to create index {}: {}", indexName, e.getMessage());
        }
    }

    @Override
    public CompletableFuture<Void> deleteAsync(Long workspaceId, List<String> documentIds) {
        return CompletableFuture.runAsync(() -> {
            if (!isAvailable()) return;
            String indexName = buildIndexName(workspaceId);
            documentIds.forEach(id -> {
                try {
                    client.delete(d -> d.index(indexName).id(id));
                } catch (Exception e) {
                    log.error("[ES] Delete failed for {}: {}", id, e.getMessage());
                }
            });
        });
    }

    @Override
    public CompletableFuture<Void> clearAsync(Long workspaceId) {
        return CompletableFuture.runAsync(() -> {
            if (!isAvailable()) return;
            try {
                client.indices().delete(d -> d.index(buildIndexName(workspaceId)));
            } catch (Exception e) {
                log.error("[ES] Clear failed: {}", e.getMessage());
            }
        });
    }

    @Override
    public CompletableFuture<VectorStats> getStatsAsync(Long workspaceId) {
        return CompletableFuture.completedFuture(new VectorStats(0, 0, "ELASTICSEARCH"));
    }
}
```

### 4.2 Milvus 提供者实现

```java
// 文件: src/main/java/vip/mate/hybrid/provider/MilvusHybridStoreProvider.java
package vip.mate.hybrid.provider;

import com.alibaba.cloud.ai.hybrid.milvus.MilvusVectorStore;
import com.alibaba.cloud.ai.hybrid.milvus.MilvusVectorStoreConfig;
import io.milvus.client.MilvusServiceClient;
import io.milvus.param.ConnectParam;
import jakarta.annotation.PostConstruct;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.ai.document.Document;
import org.springframework.ai.embedding.EmbeddingModel;
import org.springframework.ai.hybrid.SearchRequest;
import org.springframework.ai.hybrid.VectorStore;
import org.springframework.stereotype.Component;
import vip.mate.llm.embedding.EmbeddingModelFactory;
import vip.mate.hybrid.config.MilvusProperties;
import vip.mate.hybrid.spi.HybridStoreProvider;

import java.util.*;
import java.util.concurrent.CompletableFuture;
import java.util.concurrent.ConcurrentHashMap;

@Slf4j
@Component
@RequiredArgsConstructor
public class MilvusHybridStoreProvider implements HybridStoreProvider {

    private final MilvusProperties properties;
    private final EmbeddingModelFactory embeddingModelFactory;
    
    private MilvusServiceClient milvusClient;
    private final Map<Long, VectorStore> storeCache = new ConcurrentHashMap<>();
    
    @PostConstruct
    void init() {
        if (!properties.isEnabled()) {
            log.info("[Milvus] Milvus vector store is disabled");
            return;
        }
        try {
            this.milvusClient = new MilvusServiceClient(
                    ConnectParam.newBuilder()
                            .withHost(properties.getHost())
                            .withPort(properties.getPort())
                            .withConnectTimeout(properties.getConnectTimeout())
                            .build()
            );
            log.info("[Milvus] Connected to Milvus: {}:{}", properties.getHost(), properties.getPort());
        } catch (Exception e) {
            log.error("[Milvus] Failed to connect to Milvus: {}", e.getMessage());
            milvusClient = null;
        }
    }

    @Override
    public String id() {
        return "milvus";
    }

    @Override
    public int order() {
        return 10;
    }

    @Override
    public boolean isAvailable() {
        return properties.isEnabled() && milvusClient != null;
    }

    @Override
    public CompletableFuture<WriteResult> writeAsync(Long workspaceId, List<VectorDocument> documents) {
        return CompletableFuture.supplyAsync(() -> {
            if (!isAvailable()) {
                return new WriteResult(0, documents.size(), documents.stream()
                        .map(VectorDocument::id).toList());
            }
            
            VectorStore store = getOrCreateStore(workspaceId);
            if (store == null) {
                return new WriteResult(0, documents.size(), documents.stream()
                        .map(VectorDocument::id).toList());
            }
            
            List<Document> springAiDocs = documents.stream()
                    .map(doc -> new Document(doc.id(), doc.content(), doc.embedding(), doc.metadata()))
                    .toList();
            
            int successCount = 0;
            List<String> failedIds = new ArrayList<>();
            
            for (int i = 0; i < springAiDocs.size(); i += properties.getBatchSize()) {
                int end = Math.min(i + properties.getBatchSize(), springAiDocs.size());
                List<Document> batch = springAiDocs.subList(i, end);
                
                try {
                    store.add(batch);
                    successCount += batch.size();
                } catch (Exception e) {
                    log.error("[Milvus] Write batch failed: {}", e.getMessage());
                    batch.forEach(doc -> failedIds.add(doc.getId()));
                }
            }
            
            return new WriteResult(successCount, failedIds.size(), failedIds);
        });
    }

    @Override
    public CompletableFuture<RetrievalResult> retrieveAsync(Long workspaceId, String query, int topK) {
        return CompletableFuture.supplyAsync(() -> {
            if (!isAvailable()) {
                return new RetrievalResult(Collections.emptyList(), false, "Milvus not available");
            }
            
            VectorStore store = getOrCreateStore(workspaceId);
            if (store == null) {
                return new RetrievalResult(Collections.emptyList(), false, "Failed to get store");
            }
            
            try {
                EmbeddingModel embeddingModel = embeddingModelFactory.buildDefault();
                if (embeddingModel == null) {
                    return new RetrievalResult(Collections.emptyList(), false, "No embedding model");
                }
                
                SearchRequest request = SearchRequest.query(query)
                        .withTopK(topK)
                        .withSimilarityThreshold(0.7f);
                
                List<Document> results = store.similaritySearch(request);
                
                List<RetrievalHit> hits = results.stream()
                        .map(doc -> new RetrievalHit(
                                doc.getId(),
                                doc.getContent(),
                                (float) doc.getSimilarityScore(),
                                doc.getMetadata()
                        ))
                        .toList();
                
                return new RetrievalResult(hits, false, null);
                
            } catch (Exception e) {
                log.error("[Milvus] Retrieve failed: {}", e.getMessage());
                return new RetrievalResult(Collections.emptyList(), false, e.getMessage());
            }
        });
    }

    private VectorStore getOrCreateStore(Long workspaceId) {
        return storeCache.computeIfAbsent(workspaceId, id -> {
            try {
                String collectionName = buildCollectionName(id);
                ensureCollectionExists(collectionName);
                
                MilvusVectorStoreConfig config = new MilvusVectorStoreConfig();
                config.setCollectionName(collectionName);
                config.setDatabaseName(properties.getDatabase());
                config.setDimension(properties.getDimension());
                config.setIndexType(properties.getIndexType());
                config.setHnswM(properties.getHnswM());
                config.setEfConstruction(properties.getEfConstruction());
                config.setEf(properties.getEf());
                
                return new MilvusVectorStore(milvusClient, config);
            } catch (Exception e) {
                log.error("[Milvus] Failed to create store: {}", e.getMessage());
                return null;
            }
        });
    }

    private String buildCollectionName(Long workspaceId) {
        return properties.getCollectionPrefix() + "_" + workspaceId + "_vectors";
    }

    private void ensureCollectionExists(String collectionName) {
        try {
            var exists = milvusClient.hasCollection(
                    io.milvus.param.collection.HasCollectionParam.newBuilder()
                            .withCollectionName(collectionName).build());
            
            if (!exists.getData()) {
                milvusClient.createCollection(
                        io.milvus.param.collection.CreateCollectionParam.newBuilder()
                                .withCollectionName(collectionName)
                                .addFieldType(io.milvus.grpc.FieldType.newBuilder()
                                        .withName("id").withDataType(io.milvus.grpc.DataType.VarChar)
                                        .withMaxLength(64).withIsPrimaryKey(true).build())
                                .addFieldType(io.milvus.grpc.FieldType.newBuilder()
                                        .withName("embedding").withDataType(io.milvus.grpc.DataType.FloatVector)
                                        .withDimension(properties.getDimension()).build())
                                .addFieldType(io.milvus.grpc.FieldType.newBuilder()
                                        .withName("content").withDataType(io.milvus.grpc.DataType.VarChar)
                                        .withMaxLength(65535).build())
                                .addFieldType(io.milvus.grpc.FieldType.newBuilder()
                                        .withName("metadata").withDataType(io.milvus.grpc.DataType.VarChar)
                                        .withMaxLength(10240).build())
                                .build());
                
                milvusClient.createIndex(
                        io.milvus.param.index.CreateIndexParam.newBuilder()
                                .withCollectionName(collectionName)
                                .withFieldName("embedding")
                                .withIndexType(properties.getIndexType())
                                .withMetricType(io.milvus.grpc.MetricType.COSINE)
                                .withExtraParam(String.format("{\"M\": %d, \"efConstruction\": %d}",
                                        properties.getHnswM(), properties.getEfConstruction()))
                                .build());
                
                milvusClient.loadCollection(
                        io.milvus.param.collection.LoadCollectionParam.newBuilder()
                                .withCollectionName(collectionName).build());
                
                log.info("[Milvus] Created collection: {}", collectionName);
            }
        } catch (Exception e) {
            log.error("[Milvus] Failed to ensure collection: {}", e.getMessage());
            throw new RuntimeException(e);
        }
    }

    @Override
    public CompletableFuture<Void> deleteAsync(Long workspaceId, List<String> documentIds) {
        return CompletableFuture.runAsync(() -> {
            if (!isAvailable()) return;
            VectorStore store = getOrCreateStore(workspaceId);
            if (store != null) {
                try {
                    store.delete(documentIds);
                } catch (Exception e) {
                    log.error("[Milvus] Delete failed: {}", e.getMessage());
                }
            }
        });
    }

    @Override
    public CompletableFuture<Void> clearAsync(Long workspaceId) {
        return CompletableFuture.runAsync(() -> {
            if (!isAvailable()) return;
            try {
                milvusClient.dropCollection(
                        io.milvus.param.collection.DropCollectionParam.newBuilder()
                                .withCollectionName(buildCollectionName(workspaceId)).build());
                storeCache.remove(workspaceId);
            } catch (Exception e) {
                log.error("[Milvus] Clear failed: {}", e.getMessage());
            }
        });
    }

    @Override
    public CompletableFuture<VectorStats> getStatsAsync(Long workspaceId) {
        return CompletableFuture.supplyAsync(() -> {
            if (!isAvailable()) return new VectorStats(0, properties.getDimension(), "N/A");
            
            try {
                var resp = milvusClient.getCollectionStatistics(
                        io.milvus.param.collection.GetCollectionStatisticsParam.newBuilder()
                                .withCollectionName(buildCollectionName(workspaceId)).build());
                
                long total = Long.parseLong(resp.getData().getRowCount());
                return new VectorStats(total, properties.getDimension(), properties.getIndexType());
            } catch (Exception e) {
                log.warn("[Milvus] Get stats failed: {}", e.getMessage());
                return new VectorStats(0, properties.getDimension(), properties.getIndexType());
            }
        });
    }
}
```

## 五、降级机制实现

```java
// 文件: src/main/java/vip/mate/hybrid/provider/FallbackHybridStoreProvider.java
package vip.mate.hybrid.provider;

import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;
import vip.mate.llm.embedding.EmbeddingModelFactory;
import vip.mate.hybrid.spi.HybridStoreProvider;
import vip.mate.wiki.model.WikiChunkEntity;
import vip.mate.wiki.repository.WikiChunkMapper;
import vip.mate.wiki.service.WikiKnowledgeBaseService;

import java.util.*;
import java.util.concurrent.CompletableFuture;

@Slf4j
@Component
@RequiredArgsConstructor
public class FallbackHybridStoreProvider implements HybridStoreProvider {

    private final WikiKnowledgeBaseService wikiKnowledgeBaseService;
    private final WikiChunkMapper wikiChunkMapper;
    private final EmbeddingModelFactory embeddingModelFactory;

    @Override
    public String id() {
        return "fallback";
    }

    @Override
    public int order() {
        return 1000;
    }

    @Override
    public boolean isAvailable() {
        return true;
    }

    @Override
    public CompletableFuture<WriteResult> writeAsync(Long workspaceId, List<VectorDocument> documents) {
        return CompletableFuture.supplyAsync(() -> {
            if (documents.isEmpty()) {
                return new WriteResult(0, 0, List.of());
            }
            
            log.info("[Fallback] Writing {} documents to MySQL fallback store", documents.size());
            int successCount = 0;
            List<String> failedIds = new ArrayList<>();
            
            for (VectorDocument doc : documents) {
                try {
                    WikiChunkEntity chunk = new WikiChunkEntity();
                    chunk.setId(Long.parseLong(doc.id()));
                    chunk.setContent(doc.content());
                    chunk.setEmbedding(Arrays.toString(doc.embedding()));
                    wikiChunkMapper.insert(chunk);
                    successCount++;
                } catch (Exception e) {
                    log.warn("[Fallback] Failed to write document {}: {}", doc.id(), e.getMessage());
                    failedIds.add(doc.id());
                }
            }
            
            return new WriteResult(successCount, failedIds.size(), failedIds);
        });
    }

    @Override
    public CompletableFuture<RetrievalResult> retrieveAsync(Long workspaceId, String query, int topK) {
        return CompletableFuture.supplyAsync(() -> {
            log.info("[Fallback] Starting fallback retrieval for workspaceId={}", workspaceId);
            
            List<RetrievalHit> hits = new ArrayList<>();
            String errorMessage = null;
            
            try {
                hits = tryVectorRetrieval(workspaceId, query, topK);
                log.info("[Fallback] Vector retrieval succeeded, found {} hits", hits.size());
            } catch (Exception e) {
                log.warn("[Fallback] Vector retrieval failed: {}, falling back to text search", e.getMessage());
                errorMessage = "Vector retrieval failed: " + e.getMessage();
                
                try {
                    hits = tryTextRetrieval(workspaceId, query, topK);
                    log.info("[Fallback] Text retrieval succeeded, found {} hits", hits.size());
                } catch (Exception textEx) {
                    log.error("[Fallback] Text retrieval also failed: {}", textEx.getMessage());
                    errorMessage += ", Text retrieval failed: " + textEx.getMessage();
                }
            }
            
            return new RetrievalResult(hits, true, hits.isEmpty() ? errorMessage : null);
        });
    }

    private List<RetrievalHit> tryVectorRetrieval(Long workspaceId, String query, int topK) {
        var embeddingModel = embeddingModelFactory.buildDefault();
        if (embeddingModel == null) {
            throw new RuntimeException("No embedding model available for fallback");
        }

        float[] queryEmbedding = embeddingModel.embed(query);
        
        List<WikiChunkEntity> allChunks = wikiChunkMapper.selectByWorkspaceId(workspaceId);
        if (allChunks.isEmpty()) {
            throw new RuntimeException("No vector data found in MySQL");
        }

        List<RetrievalHit> hits = new ArrayList<>();
        for (WikiChunkEntity chunk : allChunks) {
            try {
                float[] chunkEmbedding = parseEmbedding(chunk.getEmbedding());
                float similarity = cosineSimilarity(queryEmbedding, chunkEmbedding);
                
                hits.add(new RetrievalHit(
                        chunk.getId().toString(),
                        chunk.getContent(),
                        similarity,
                        Map.of("chunkId", chunk.getId(), "pageId", chunk.getPageId())
                ));
            } catch (Exception e) {
                log.debug("[Fallback] Failed to process chunk {}: {}", chunk.getId(), e.getMessage());
            }
        }

        hits.sort((a, b) -> Float.compare(b.score(), a.score()));
        return hits.stream().limit(topK).toList();
    }

    private List<RetrievalHit> tryTextRetrieval(Long workspaceId, String query, int topK) {
        return wikiKnowledgeBaseService.searchByText(workspaceId, query, topK)
                .stream()
                .map(result -> new RetrievalHit(
                        result.getPageId().toString(),
                        result.getContent(),
                        result.getScore(),
                        Map.of("pageTitle", result.getTitle(), "kbId", result.getKbId())
                ))
                .toList();
    }

    private float[] parseEmbedding(String embeddingStr) {
        if (embeddingStr == null || embeddingStr.isEmpty()) {
            return new float[0];
        }
        String cleanStr = embeddingStr.replace("[", "").replace("]", "").trim();
        String[] parts = cleanStr.split(",");
        float[] embedding = new float[parts.length];
        for (int i = 0; i < parts.length; i++) {
            embedding[i] = Float.parseFloat(parts[i].trim());
        }
        return embedding;
    }

    private float cosineSimilarity(float[] a, float[] b) {
        if (a.length != b.length || a.length == 0) {
            return 0f;
        }
        float dotProduct = 0;
        float normA = 0;
        float normB = 0;
        for (int i = 0; i < a.length; i++) {
            dotProduct += a[i] * b[i];
            normA += a[i] * a[i];
            normB += b[i] * b[i];
        }
        if (normA == 0 || normB == 0) {
            return 0f;
        }
        return dotProduct / (float)(Math.sqrt(normA) * Math.sqrt(normB));
    }

    @Override
    public CompletableFuture<Void> deleteAsync(Long workspaceId, List<String> documentIds) {
        return CompletableFuture.runAsync(() -> {
            log.info("[Fallback] Deleting {} documents", documentIds.size());
            documentIds.forEach(id -> {
                try {
                    wikiChunkMapper.deleteById(Long.parseLong(id));
                } catch (Exception e) {
                    log.warn("[Fallback] Failed to delete document {}: {}", id, e.getMessage());
                }
            });
        });
    }

    @Override
    public CompletableFuture<Void> clearAsync(Long workspaceId) {
        return CompletableFuture.runAsync(() -> {
            log.info("[Fallback] Clearing all documents for workspace {}", workspaceId);
            try {
                wikiChunkMapper.deleteByWorkspaceId(workspaceId);
            } catch (Exception e) {
                log.error("[Fallback] Clear failed: {}", e.getMessage());
            }
        });
    }

    @Override
    public CompletableFuture<VectorStats> getStatsAsync(Long workspaceId) {
        return CompletableFuture.supplyAsync(() -> {
            try {
                long count = wikiChunkMapper.countByWorkspaceId(workspaceId);
                return new VectorStats(count, 1024, "MYSQL_FALLBACK");
            } catch (Exception e) {
                log.warn("[Fallback] Get stats failed: {}", e.getMessage());
                return new VectorStats(0, 0, "MYSQL_FALLBACK");
            }
        });
    }
}
```

```java
package vip.mate.hybrid;

import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;
import vip.mate.hybrid.spi.HybridStoreProvider;

import java.util.Comparator;
import java.util.List;
import java.util.ServiceLoader;
import java.util.concurrent.CopyOnWriteArrayList;

@Slf4j
@Component
public class HybridStoreManager {

    private final List<HybridStoreProvider> providers = new CopyOnWriteArrayList<>();
    private volatile HybridStoreProvider activeProvider;
    private volatile HybridStoreProvider esProvider;

    @PostConstruct
    void init() {
        ServiceLoader<HybridStoreProvider> loader = ServiceLoader.load(HybridStoreProvider.class);
        
        for (HybridStoreProvider provider : loader) {
            providers.add(provider);
            log.info("[VectorStore] Loaded provider: {} (order={})", provider.id(), provider.order());
            
            if ("elasticsearch".equals(provider.id())) {
                esProvider = provider;
            }
        }
        
        providers.sort(Comparator.comparingInt(HybridStoreProvider::order));
        refreshActiveProvider();
    }

    public void refreshActiveProvider() {
        for (HybridStoreProvider provider : providers) {
            if (provider.isAvailable() && !"elasticsearch".equals(provider.id())) {
                activeProvider = provider;
                log.info("[VectorStore] Active provider set to: {}", provider.id());
                return;
            }
        }
        log.warn("[VectorStore] No available provider found");
        activeProvider = null;
    }

    public HybridStoreProvider getActiveProvider() {
        if (activeProvider == null) {
            refreshActiveProvider();
        }
        return activeProvider;
    }

    public HybridStoreProvider getEsProvider() {
        return esProvider;
    }

    public HybridStoreProvider getProvider(String providerId) {
        return providers.stream()
                .filter(p -> p.id().equals(providerId))
                .findFirst()
                .orElse(null);
    }

    public HybridStoreProvider.RetrievalResult retrieve(Long workspaceId, String query, int topK) {
        HybridStoreProvider provider = getActiveProvider();
        if (provider == null) {
            log.error("[VectorStore] No provider available");
            return new HybridStoreProvider.RetrievalResult(List.of(), false, "No provider available");
        }
        
        try {
            return provider.retrieveAsync(workspaceId, query, topK).get();
        } catch (Exception e) {
            log.error("[VectorStore] Retrieval failed: {}", e.getMessage());
            HybridStoreProvider fallback = getProvider("fallback");
            if (fallback != null) {
                try {
                    return fallback.retrieveAsync(workspaceId, query, topK).get();
                } catch (Exception fallbackEx) {
                    log.error("[VectorStore] Fallback also failed: {}", fallbackEx.getMessage());
                }
            }
            return new HybridStoreProvider.RetrievalResult(List.of(), true, e.getMessage());
        }
    }

    public List<HybridStoreProvider> getAllProviders() {
        return List.copyOf(providers);
    }
}
```

```java
// 文件: src/main/java/vip/mate/hybrid/service/DocumentChunkService.java
package vip.mate.hybrid.service;

import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;
import vip.mate.wiki.model.WikiChunkEntity;
import vip.mate.wiki.repository.WikiChunkMapper;

import java.util.ArrayList;
import java.util.List;
import java.util.regex.Pattern;

@Slf4j
@Service
@RequiredArgsConstructor
public class DocumentChunkService {

    private final WikiChunkMapper wikiChunkMapper;
    
    private static final int DEFAULT_CHUNK_SIZE = 512;
    private static final int DEFAULT_CHUNK_OVERLAP = 64;
    private static final Pattern SENTENCE_SEPARATORS = Pattern.compile("[。！？；;\\n\\r]");
    private static final Pattern PARAGRAPH_SEPARATORS = Pattern.compile("\\n\\s*\\n");

    public enum ChunkStrategy {
        SENTENCE_BASED,    // 基于句子切分（保证语义完整）
        PARAGRAPH_BASED,   // 基于段落切分
        FIXED_LENGTH       // 固定长度切分（带重叠）
    }

    public List<WikiChunkEntity> chunkDocument(Long pageId, Long kbId, String content) {
        return chunkDocument(pageId, kbId, content, ChunkStrategy.SENTENCE_BASED, 
                DEFAULT_CHUNK_SIZE, DEFAULT_CHUNK_OVERLAP);
    }

    public List<WikiChunkEntity> chunkDocument(Long pageId, Long kbId, String content, 
            ChunkStrategy strategy, int chunkSize, int overlap) {
        
        List<WikiChunkEntity> chunks = new ArrayList<>();
        
        if (content == null || content.isEmpty()) {
            return chunks;
        }

        List<String> segments = switch (strategy) {
            case SENTENCE_BASED -> splitBySentence(content);
            case PARAGRAPH_BASED -> splitByParagraph(content);
            case FIXED_LENGTH -> splitByFixedLength(content, chunkSize, overlap);
        };

        int chunkIndex = 0;
        StringBuilder currentChunk = new StringBuilder();
        
        for (String segment : segments) {
            if (currentChunk.length() + segment.length() <= chunkSize) {
                if (currentChunk.length() > 0) {
                    currentChunk.append("。");
                }
                currentChunk.append(segment);
            } else {
                if (currentChunk.length() > 0) {
                    chunks.add(createChunk(pageId, kbId, currentChunk.toString(), chunkIndex++));
                }
                currentChunk = new StringBuilder(segment);
            }
        }
        
        if (currentChunk.length() > 0) {
            chunks.add(createChunk(pageId, kbId, currentChunk.toString(), chunkIndex));
        }

        log.info("[ChunkService] Created {} chunks for page {}", chunks.size(), pageId);
        return chunks;
    }

    private List<String> splitBySentence(String content) {
        List<String> sentences = new ArrayList<>();
        String[] parts = SENTENCE_SEPARATORS.split(content);
        for (String part : parts) {
            String trimmed = part.trim();
            if (!trimmed.isEmpty()) {
                sentences.add(trimmed);
            }
        }
        return sentences;
    }

    private List<String> splitByParagraph(String content) {
        List<String> paragraphs = new ArrayList<>();
        String[] parts = PARAGRAPH_SEPARATORS.split(content);
        for (String part : parts) {
            String trimmed = part.trim();
            if (!trimmed.isEmpty()) {
                paragraphs.add(trimmed);
            }
        }
        return paragraphs;
    }

    private List<String> splitByFixedLength(String content, int chunkSize, int overlap) {
        List<String> chunks = new ArrayList<>();
        int start = 0;
        
        while (start < content.length()) {
            int end = Math.min(start + chunkSize, content.length());
            if (end < content.length()) {
                int lastPeriod = content.lastIndexOf('。', end);
                int lastQuestion = content.lastIndexOf('？', end);
                int lastExclaim = content.lastIndexOf('！', end);
                int splitPoint = Math.max(Math.max(lastPeriod, lastQuestion), lastExclaim);
                
                if (splitPoint > start + chunkSize / 2) {
                    end = splitPoint + 1;
                }
            }
            
            chunks.add(content.substring(start, end).trim());
            start = end - overlap;
            
            if (start <= 0 || start >= content.length()) {
                break;
            }
        }
        
        return chunks;
    }

    private WikiChunkEntity createChunk(Long pageId, Long kbId, String content, int index) {
        WikiChunkEntity chunk = new WikiChunkEntity();
        chunk.setPageId(pageId);
        chunk.setKbId(kbId);
        chunk.setContent(content);
        chunk.setChunkIndex(index);
        chunk.setCharCount(content.length());
        return chunk;
    }

    public void saveChunks(List<WikiChunkEntity> chunks) {
        if (!chunks.isEmpty()) {
            wikiChunkMapper.batchInsert(chunks);
        }
    }
}
```

```java
package vip.mate.hybrid.util;

import lombok.extern.slf4j.Slf4j;

import java.time.LocalDateTime;
import java.util.concurrent.atomic.AtomicInteger;
import java.util.concurrent.atomic.AtomicReference;

@Slf4j
public class CircuitBreaker {

    private final String name;
    private final int failureThreshold;
    private final long resetTimeoutMs;
    
    private final AtomicInteger failureCount = new AtomicInteger(0);
    private final AtomicReference<State> state = new AtomicReference<>(State.CLOSED);
    private volatile LocalDateTime lastFailureTime;

    public enum State {
        CLOSED,      // 正常状态
        OPEN,        // 熔断状态
        HALF_OPEN    // 探测状态
    }

    public CircuitBreaker(String name) {
        this(name, 3, 60000);
    }

    public CircuitBreaker(String name, int failureThreshold, long resetTimeoutMs) {
        this.name = name;
        this.failureThreshold = failureThreshold;
        this.resetTimeoutMs = resetTimeoutMs;
    }

    public boolean shouldFallback() {
        State currentState = state.get();
        
        if (currentState == State.OPEN) {
            if (shouldReset()) {
                state.compareAndSet(State.OPEN, State.HALF_OPEN);
                log.info("[CircuitBreaker] {} transitioning to HALF_OPEN for probe", name);
                return false;
            }
            log.debug("[CircuitBreaker] {} is OPEN, using fallback", name);
            return true;
        }
        
        return false;
    }

    public void recordSuccess() {
        failureCount.set(0);
        state.compareAndSet(State.HALF_OPEN, State.CLOSED);
        log.debug("[CircuitBreaker] {} recorded success, state reset", name);
    }

    public void recordFailure() {
        int count = failureCount.incrementAndGet();
        lastFailureTime = LocalDateTime.now();
        
        if (count >= failureThreshold && state.compareAndSet(State.CLOSED, State.OPEN)) {
            log.warn("[CircuitBreaker] {} tripped after {} failures", name, count);
        } else if (state.get() == State.HALF_OPEN) {
            state.compareAndSet(State.HALF_OPEN, State.OPEN);
            log.warn("[CircuitBreaker] {} probe failed, staying OPEN", name);
        }
    }

    public State getState() {
        return state.get();
    }

    private boolean shouldReset() {
        if (lastFailureTime == null) {
            return true;
        }
        long elapsedMs = java.time.Duration.between(lastFailureTime, LocalDateTime.now()).toMillis();
        return elapsedMs >= resetTimeoutMs;
    }

    public int getFailureCount() {
        return failureCount.get();
    }
}
```

```java
// 文件: src/main/java/vip/mate/hybrid/service/MilvusAsyncEmbeddingService.java
package vip.mate.hybrid.service;

import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.scheduling.annotation.Async;
import org.springframework.stereotype.Service;
import vip.mate.llm.embedding.EmbeddingModelFactory;
import vip.mate.hybrid.HybridStoreManager;
import vip.mate.hybrid.spi.HybridStoreProvider;
import vip.mate.wiki.model.WikiChunkEntity;
import vip.mate.wiki.repository.WikiChunkMapper;

import java.util.List;
import java.util.Map;
import java.util.UUID;
import java.util.stream.Collectors;

@Slf4j
@Service
@RequiredArgsConstructor
public class MilvusAsyncEmbeddingService {

    private final HybridStoreManager HybridStoreManager;
    private final EmbeddingModelFactory embeddingModelFactory;
    private final WikiChunkMapper wikiChunkMapper;
    private final EmbeddingRetryService embeddingRetryService;

    private static final int MAX_RETRY_ATTEMPTS = 3;
    private static final long RETRY_DELAY_MS = 5000;

    @Async("embeddingThreadPool")
    public void embedAndStoreAsync(Long kbId, Long workspaceId) {
        log.info("[MilvusAsync] Starting async embedding for kbId={}, workspaceId={}", kbId, workspaceId);
        
        try {
            List<WikiChunkEntity> chunks = wikiChunkMapper.selectByKbId(kbId);
            if (chunks.isEmpty()) {
                log.info("[MilvusAsync] No chunks found");
                return;
            }
            
            var embeddingModel = embeddingModelFactory.buildDefault();
            if (embeddingModel == null) {
                log.error("[MilvusAsync] No embedding model available");
                return;
            }
            
            List<HybridStoreProvider.VectorDocument> documents = chunks.stream()
                    .map(chunk -> {
                        try {
                            float[] embedding = embeddingWithRetry(chunk.getContent(), chunk.getId());
                            return new HybridStoreProvider.VectorDocument(
                                    chunk.getId().toString(),
                                    chunk.getContent(),
                                    embedding,
                                    Map.of("chunkId", chunk.getId(), "kbId", kbId,
                                            "pageId", chunk.getPageId(), "rawId", chunk.getRawId())
                            );
                        } catch (EmbeddingRetryException e) {
                            log.error("[MilvusAsync] Failed to embed chunk {} after {} retries", 
                                    chunk.getId(), e.getRetryCount());
                            embeddingRetryService.recordFailedChunk(chunk.getId(), kbId, workspaceId);
                            return null;
                        } catch (Exception e) {
                            log.warn("[MilvusAsync] Failed to embed chunk {}: {}", chunk.getId(), e.getMessage());
                            embeddingRetryService.recordFailedChunk(chunk.getId(), kbId, workspaceId);
                            return null;
                        }
                    })
                    .filter(doc -> doc != null)
                    .collect(Collectors.toList());
            
            if (documents.isEmpty()) {
                log.warn("[MilvusAsync] All chunks failed to embed");
                return;
            }
            
            writeWithRetry(workspaceId, documents, kbId);
            
        } catch (Exception e) {
            log.error("[MilvusAsync] Unexpected error: {}", e.getMessage(), e);
        }
    }

    private float[] embeddingWithRetry(String content, Long chunkId) throws EmbeddingRetryException {
        var embeddingModel = embeddingModelFactory.buildDefault();
        Exception lastException = null;
        
        for (int attempt = 1; attempt <= MAX_RETRY_ATTEMPTS; attempt++) {
            try {
                return embeddingModel.embed(content);
            } catch (Exception e) {
                lastException = e;
                log.warn("[MilvusAsync] Embedding attempt {} failed for chunk {}: {}", 
                        attempt, chunkId, e.getMessage());
                
                if (attempt < MAX_RETRY_ATTEMPTS) {
                    try {
                        Thread.sleep(RETRY_DELAY_MS * attempt);
                    } catch (InterruptedException ie) {
                        Thread.currentThread().interrupt();
                        throw new EmbeddingRetryException(attempt, ie);
                    }
                }
            }
        }
        
        throw new EmbeddingRetryException(MAX_RETRY_ATTEMPTS, lastException);
    }

    private void writeWithRetry(Long workspaceId, List<HybridStoreProvider.VectorDocument> documents, Long kbId) {
        Exception lastException = null;
        
        for (int attempt = 1; attempt <= MAX_RETRY_ATTEMPTS; attempt++) {
            try {
                var result = HybridStoreManager.getActiveProvider()
                        .writeAsync(workspaceId, documents)
                        .get();
                
                log.info("[MilvusAsync] Write completed: {}/{} succeeded", 
                        result.successCount(), documents.size());
                
                if (result.failedCount() > 0) {
                    log.warn("[MilvusAsync] {} documents failed to write, scheduling retry", result.failedCount());
                    embeddingRetryService.recordFailedDocuments(kbId, workspaceId, result.failedIds());
                }
                return;
                
            } catch (Exception e) {
                lastException = e;
                log.warn("[MilvusAsync] Write attempt {} failed: {}", attempt, e.getMessage());
                
                if (attempt < MAX_RETRY_ATTEMPTS) {
                    try {
                        Thread.sleep(RETRY_DELAY_MS * attempt);
                    } catch (InterruptedException ie) {
                        Thread.currentThread().interrupt();
                        break;
                    }
                }
            }
        }
        
        log.error("[MilvusAsync] Write failed after {} attempts: {}", MAX_RETRY_ATTEMPTS, lastException.getMessage());
        embeddingRetryService.recordFailedDocuments(kbId, workspaceId, 
                documents.stream().map(HybridStoreProvider.VectorDocument::id).toList());
    }

    public HybridStoreProvider.RetrievalResult retrieve(Long workspaceId, String query, int topK) {
        return HybridStoreManager.retrieve(workspaceId, query, topK);
    }

    public static class EmbeddingRetryException extends Exception {
        private final int retryCount;
        
        public EmbeddingRetryException(int retryCount, Throwable cause) {
            super("Failed after " + retryCount + " attempts", cause);
            this.retryCount = retryCount;
        }
        
        public int getRetryCount() {
            return retryCount;
        }
    }
}
```

```java
        for (String id : failedIds) {
            try {
                Long chunkId = Long.parseLong(id);
                recordFailedChunk(chunkId, kbId, workspaceId);
            } catch (NumberFormatException e) {
                log.warn("[RetryService] Invalid chunk id: {}", id);
            }
        }
    }

    @Scheduled(fixedDelay = 60000)
    @Transactional(rollbackFor = Exception.class)
    public void processRetryQueue() {
        log.debug("[RetryService] Processing retry queue");
        
        List<EmbeddingTaskEntity> tasks = embeddingTaskMapper.selectPendingTasks(BATCH_SIZE);
        if (tasks.isEmpty()) {
            return;
        }
        
        log.info("[RetryService] Found {} pending tasks", tasks.size());
        
        var embeddingModel = embeddingModelFactory.buildDefault();
        if (embeddingModel == null) {
            log.error("[RetryService] No embedding model available for retry");
            return;
        }
        
        for (EmbeddingTaskEntity task : tasks) {
            try {
                processTask(task, embeddingModel);
            } catch (Exception e) {
                log.error("[RetryService] Failed to process task {}: {}", task.getId(), e.getMessage());
            }
        }
    }

    private void processTask(EmbeddingTaskEntity task, var embeddingModel) {
        WikiChunkEntity chunk = wikiChunkMapper.selectById(task.getChunkId());
        if (chunk == null) {
            log.warn("[RetryService] Chunk {} not found, removing task", task.getChunkId());
            embeddingTaskMapper.deleteById(task.getId());
            return;
        }

        try {
            float[] embedding = embeddingModel.embed(chunk.getContent());
            
            var document = new HybridStoreProvider.VectorDocument(
                    chunk.getId().toString(),
                    chunk.getContent(),
                    embedding,
                    Map.of("chunkId", chunk.getId(), "kbId", task.getKbId(),
                            "pageId", chunk.getPageId(), "rawId", chunk.getRawId())
            );
            
            var result = HybridStoreManager.getActiveProvider()
                    .writeAsync(task.getWorkspaceId(), List.of(document))
                    .get();
            
            if (result.successCount() > 0) {
                task.setStatus("SUCCESS");
                task.setErrorMessage(null);
                log.info("[RetryService] Task {} succeeded after {} retries", 
                        task.getId(), task.getRetryCount());
            } else {
                updateTaskForRetry(task, "Write failed");
            }
            
        } catch (Exception e) {
            updateTaskForRetry(task, e.getMessage());
        }
        
        embeddingTaskMapper.updateById(task);
    }

    private void updateTaskForRetry(EmbeddingTaskEntity task, String errorMessage) {
        int newRetryCount = task.getRetryCount() + 1;
        
        if (newRetryCount >= MAX_RETRY_COUNT) {
            task.setStatus("ABORTED");
            task.setErrorMessage("Max retry count exceeded: " + errorMessage);
            log.error("[RetryService] Task {} aborted after {} retries", task.getId(), newRetryCount);
        } else {
            long delayMinutes = (long) Math.pow(2, newRetryCount) * 5;
            task.setStatus("PENDING");
            task.setRetryCount(newRetryCount);
            task.setNextRetryTime(LocalDateTime.now().plusMinutes(delayMinutes));
            task.setErrorMessage(errorMessage);
            log.warn("[RetryService] Task {} scheduled for retry {} in {} minutes", 
                    task.getId(), newRetryCount, delayMinutes);
        }
    }

    public int getPendingTaskCount() {
        return embeddingTaskMapper.countPendingTasks();
    }

    public List<EmbeddingTaskEntity> getPendingTasks() {
        return embeddingTaskMapper.selectPendingTasks(Integer.MAX_VALUE);
    }

    @Transactional(rollbackFor = Exception.class)
    public void retryAllFailedTasks() {
        List<EmbeddingTaskEntity> tasks = embeddingTaskMapper.selectByStatus("FAILED");
        log.info("[RetryService] Resetting {} failed tasks for immediate retry", tasks.size());
        
        for (EmbeddingTaskEntity task : tasks) {
            task.setStatus("PENDING");
            task.setNextRetryTime(LocalDateTime.now());
            embeddingTaskMapper.updateById(task);
        }
    }
}
```

```java
                    .whenComplete((result, error) -> {
                        if (error != null) {
                            log.error("[ESSync] Sync failed: {}", error.getMessage());
                        } else {
                            log.info("[ESSync] Completed: {}/{} succeeded", 
                                    result.successCount(), documents.size());
                        }
                    });
            
        } catch (Exception e) {
            log.error("[ESSync] Failed: {}", e.getMessage());
        }

            log.error("[ESSync] Search failed: {}", e.getMessage());
            return new HybridStoreProvider.RetrievalResult(List.of(), false, e.getMessage());
        }
```

```java
            return;
        }

        try {
            HybridStoreProvider milvusProvider = HybridStoreManager.getActiveProvider();
            HybridStoreProvider esProvider = HybridStoreManager.getEsProvider();

            List<WikiChunkEntity> chunks = wikiChunkMapper.selectByPageId(pageId);

                esProvider.deleteAsync(workspaceId, List.of(pageId.toString()));
            }

            wikiPageMapper.deleteById(pageId);

            log.info("[Consistency] Document deleted: pageId={}", pageId);
            
        } catch (Exception e) {

        }
```

## 十五、混合检索器（带熔断降级）

```java
// 文件: src/main/java/vip/mate/wiki/service/HybridRetriever.java
package vip.mate.wiki.service;

import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;
import vip.mate.hybrid.provider.FallbackHybridStoreProvider;
import vip.mate.hybrid.service.ElasticsearchSyncService;
import vip.mate.hybrid.service.MilvusAsyncEmbeddingService;
import vip.mate.hybrid.spi.HybridStoreProvider;
import vip.mate.hybrid.util.CircuitBreaker;

import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.concurrent.CompletableFuture;
import java.util.concurrent.TimeUnit;
import java.util.stream.Collectors;

@Slf4j
@Service
@RequiredArgsConstructor
public class HybridRetriever {

    private final ElasticsearchSyncService esService;
    private final MilvusAsyncEmbeddingService milvusService;
    private final FallbackHybridStoreProvider fallbackProvider;

    private final CircuitBreaker esCircuitBreaker = new CircuitBreaker("ES", 3, 60000);
    private final CircuitBreaker milvusCircuitBreaker = new CircuitBreaker("Milvus", 3, 60000);
    private final CircuitBreaker hybridCircuitBreaker = new CircuitBreaker("Hybrid", 3, 60000);

    public enum RetrievalMode {
        ES_ONLY,        // 仅 Elasticsearch 全文检索
        VECTOR_ONLY,    // 仅 Milvus 混合检索
        HYBRID          // 混合检索（融合结果）
    }

    public HybridResult retrieve(Long workspaceId, String query, int topK, RetrievalMode mode) {
        log.info("[HybridRetriever] Mode={}, ES State={}, Milvus State={}", 
                mode, esCircuitBreaker.getState(), milvusCircuitBreaker.getState());

        if (hybridCircuitBreaker.shouldFallback()) {
            log.warn("[HybridRetriever] Hybrid circuit breaker OPEN, using full fallback");
            List<SearchHit> fallbackHits = executeFullFallback(workspaceId, query, topK);
            return new HybridResult(fallbackHits, 0, 0, true);
        }

        List<SearchHit> esHits = List.of();
        List<SearchHit> vectorHits = List.of();
        boolean esSuccess = false;
        boolean milvusSuccess = false;
        boolean fallbackUsed = false;

        CompletableFuture<List<SearchHit>> esFuture = CompletableFuture.supplyAsync(() -> {
            if (mode == RetrievalMode.VECTOR_ONLY) {
                return List.<SearchHit>of();
            }
            
            if (esCircuitBreaker.shouldFallback()) {
                log.warn("[HybridRetriever] ES circuit breaker OPEN, skipping ES");
                return List.<SearchHit>of();
            }
            
            try {
                HybridStoreProvider.RetrievalResult result = esService.search(workspaceId, query, topK * 3);
                esSuccess = result.success();
                if (esSuccess) {
                    esCircuitBreaker.recordSuccess();
                    return convertEsHits(result);
                } else {
                    esCircuitBreaker.recordFailure();
                    return List.<SearchHit>of();
                }
            } catch (Exception e) {
                esCircuitBreaker.recordFailure();
                log.error("[HybridRetriever] ES search failed: {}", e.getMessage());
                return List.<SearchHit>of();
            }
        });

        CompletableFuture<List<SearchHit>> vectorFuture = CompletableFuture.supplyAsync(() -> {
            if (mode == RetrievalMode.ES_ONLY) {
                return List.<SearchHit>of();
            }
            
            if (milvusCircuitBreaker.shouldFallback()) {
                log.warn("[HybridRetriever] Milvus circuit breaker OPEN, using MySQL vector fallback");
                fallbackUsed = true;
                return executeMysqlVectorSearch(workspaceId, query, topK * 3);
            }
            
            try {
                HybridStoreProvider.RetrievalResult result = milvusService.retrieve(workspaceId, query, topK * 3);
                milvusSuccess = result.success();
                if (milvusSuccess) {
                    milvusCircuitBreaker.recordSuccess();
                    return convertVectorHits(result);
                } else {
                    milvusCircuitBreaker.recordFailure();
                    fallbackUsed = true;
                    return executeMysqlVectorSearch(workspaceId, query, topK * 3);
                }
            } catch (Exception e) {
                milvusCircuitBreaker.recordFailure();
                fallbackUsed = true;
                log.warn("[HybridRetriever] Milvus failed, using MySQL vector fallback: {}", e.getMessage());
                return executeMysqlVectorSearch(workspaceId, query, topK * 3);
            }
        });

        try {
            CompletableFuture.allOf(esFuture, vectorFuture).get(30, TimeUnit.SECONDS);
            esHits = esFuture.get();
            vectorHits = vectorFuture.get();
        } catch (Exception e) {
            log.error("[HybridRetriever] Timeout or error: {}", e.getMessage());
        }

        if (!esSuccess && !milvusSuccess) {
            hybridCircuitBreaker.recordFailure();
            log.warn("[HybridRetriever] Both engines failed, using full fallback");
            List<SearchHit> fallbackHits = executeFullFallback(workspaceId, query, topK);
            return new HybridResult(fallbackHits, 0, 0, true);
        }

        if (esSuccess || milvusSuccess) {
            hybridCircuitBreaker.recordSuccess();
        }

        List<SearchHit> mergedHits = switch (mode) {
            case ES_ONLY -> esHits;
            case VECTOR_ONLY -> vectorHits;
            case HYBRID -> mergeAndRerank(esHits, vectorHits, topK);
        };

        return new HybridResult(mergedHits, esHits.size(), vectorHits.size(), fallbackUsed);
    }

    private List<SearchHit> convertEsHits(HybridStoreProvider.RetrievalResult result) {
        return result.hits().stream()
                .map(hit -> new SearchHit(
                        "es:" + hit.id(),
                        hit.metadata() != null ? hit.metadata().get("title") : null,
                        hit.content(),
                        hit.score(),
                        "ES",
                        hit.metadata()
                ))
                .collect(Collectors.toList());
    }

    private List<SearchHit> convertVectorHits(HybridStoreProvider.RetrievalResult result) {
        return result.hits().stream()
                .map(hit -> new SearchHit(
                        "vector:" + hit.id(),
                        hit.metadata() != null ? hit.metadata().get("pageTitle") : null,
                        hit.content(),
                        hit.score(),
                        "VECTOR",
                        hit.metadata()
                ))
                .collect(Collectors.toList());
    }

    private List<SearchHit> executeMysqlVectorSearch(Long workspaceId, String query, int topK) {
        try {
            var result = fallbackProvider.retrieveAsync(workspaceId, query, topK).get();
            return result.hits().stream()
                    .map(hit -> new SearchHit(
                            "mysql-vector:" + hit.id(),
                            null,
                            hit.content(),
                            hit.score(),
                            "MYSQL_VECTOR",
                            hit.metadata()
                    ))
                    .collect(Collectors.toList());
        } catch (Exception e) {
            log.error("[HybridRetriever] MySQL vector search failed: {}", e.getMessage());
            return List.of();
        }
    }

    private List<SearchHit> executeFullFallback(Long workspaceId, String query, int topK) {
        try {
            var result = fallbackProvider.retrieveAsync(workspaceId, query, topK).get();
            return result.hits().stream()
                    .map(hit -> new SearchHit(
                            "fallback:" + hit.id(),
                            null,
                            hit.content(),
                            hit.score(),
                            "FALLBACK",
                            hit.metadata()
                    ))
                    .collect(Collectors.toList());
        } catch (Exception e) {
            log.error("[HybridRetriever] Full fallback failed: {}", e.getMessage());
            return List.of();
        }
    }

    /**
     * RRF (Reciprocal Rank Fusion) 融合算法
     * score = Σ 1/(k + rank_i)
     */
    private List<SearchHit> mergeAndRerank(List<SearchHit> esHits, List<SearchHit> vectorHits, int topK) {
        final int k = 60; // RRF 参数
        
        Map<String, Double> fusedScores = new java.util.LinkedHashMap<>();
        Map<String, SearchHit> hitMap = new java.util.LinkedHashMap<>();

        // ES 结果排名
        for (int i = 0; i < esHits.size(); i++) {
            SearchHit hit = esHits.get(i);
            String key = generateDedupKey(hit);
            fusedScores.merge(key, 1.0 / (k + i + 1), Double::sum);
            hitMap.putIfAbsent(key, hit);
        }

        // 向量结果排名（包含 MySQL 向量）
        for (int i = 0; i < vectorHits.size(); i++) {
            SearchHit hit = vectorHits.get(i);
            String key = generateDedupKey(hit);
            fusedScores.merge(key, 1.0 / (k + i + 1), Double::sum);
            
            if (!hitMap.containsKey(key)) {
                hitMap.put(key, hit);
            }
        }

        // 重新构建结果
        return fusedScores.entrySet().stream()
                .sorted(Map.Entry.<String, Double>comparingByValue().reversed())
                .limit(topK)
                .map(entry -> {
                    SearchHit original = hitMap.get(entry.getKey());
                    return new SearchHit(
                            original.id(),
                            original.title(),
                            original.content(),
                            entry.getValue().floatValue(),
                            "HYBRID",
                            original.metadata()
                    );
                })
                .collect(Collectors.toList());
    }

    private String generateDedupKey(SearchHit hit) {
        String content = hit.content() != null ? hit.content() : "";
        String trimmed = content.length() > 100 ? content.substring(0, 100) : content;
        return String.valueOf(trimmed.hashCode());
    }

    public record SearchHit(String id, String title, String content, 
                            float score, String source, Map<String, Object> metadata) {}

    public record HybridResult(List<SearchHit> hits, int esHitCount, 
                               int vectorHitCount, boolean vectorFallbackUsed) {}
}
```

```java
                        sb.append("标题: ").append(hit.title()).append("\n");
                    }
                    sb.append("来源: ").append(hit.source()).append("\n");
                    sb.append("内容: ").append(truncateContent(hit.content(), 300)).append("\n\n");
                    
                    if (hit.metadata() != null && !hit.metadata().isEmpty()) {
                        sb.append("元数据: ").append(hit.metadata()).append("\n\n");
                    }
                }
            }
            
            if (result.vectorFallbackUsed()) {
                sb.append("⚠️ 使用降级检索模式\n");
            }
            
            sb.append(String.format("\n检索统计: ES命中 %d 条, 向量命中 %d 条", 
                    result.esHitCount(), result.vectorHitCount()));
            
            return sb.toString();

        } catch (Exception e) {
            log.error("[KnowledgeTool] Retrieval failed: {}", e.getMessage());
            return "检索失败: " + e.getMessage();
        }
    }

    private HybridRetriever.RetrievalMode parseMode(String mode) {
        return switch (mode.toLowerCase()) {
            case "es_only" -> HybridRetriever.RetrievalMode.ES_ONLY;
            case "vector_only" -> HybridRetriever.RetrievalMode.VECTOR_ONLY;
            default -> HybridRetriever.RetrievalMode.HYBRID;
        };
    }

    private String truncateContent(String content, int maxLength) {
        if (content == null) return "";
        return content.length() > maxLength 
                ? content.substring(0, maxLength) + "..." 
                : content;
    }
}
```

## 十五、Chunk 级长期记忆优化方案

### 15.1 问题背景

原项目的长期记忆形成机制基于**文件级别**计算召回频率，存在以下问题：
- 召回整个文件时，即使只有部分内容相关，也会将整个文件标记为长期记忆
- 容易加载不必要的知识，增加上下文负担
- 粒度较粗，无法精准识别真正有价值的知识片段

### 15.2 优化方案：Chunk 级别记忆

通过将召回频率统计从文件级别细化到 **Chunk 级别**，实现更精准的长期记忆形成：

```
┌─────────────────────────────────────────────────────────────────┐
│                    Chunk 级别长期记忆形成                       │
├─────────────────────────────────────────────────────────────────┤
│                                                               │
│  用户查询                                                       │
│      │                                                         │
│      ▼                                                         │
│  HybridRetriever.retrieve()                                    │
│      │                                                         │
│      │  基于 VectorStore 检索相关 Chunk                         │
│      ▼                                                         │
│  recordChunkRecall(chunkId, content, queryHash)               │
│      │                                                         │
│      │  - 记录每个 Chunk 的召回次数                             │
│      │  - 记录查询多样性（不同查询触发）                        │
│      ▼                                                         │
│  Dreaming (定时触发)                                           │
│      │                                                         │
│      │  computeScores()                                        │
│      │    ├─ 五维度评分（频率/新鲜度/多样性/时效性/增长速度）    │
│      │    └─ 按文件聚合高评分 Chunk                            │
│      ▼                                                         │
│  markPromoted() → 整合到 MEMORY.md                             │
│      │                                                         │

│                                                               │
```

```java
// 文件: MemoryRecallService.java

/**
 * 记录一次 Chunk 召回（新增方法）
 */
public void recordChunkRecall(Long agentId, Long chunkId, String contentPreview, 
                              String userQueryHash, Long pageId, String filename) {
    if (agentId == null || chunkId == null) {
        return;
    }

    String preview = contentPreview != null && contentPreview.length() > 200
            ? contentPreview.substring(0, 200)
            : contentPreview;

    // 使用 chunkId 作为唯一标识
    String uniqueKey = "chunk:" + chunkId;
    
    MemoryRecallEntity existing = recallMapper.selectOne(
            new LambdaQueryWrapper<MemoryRecallEntity>()
                    .eq(MemoryRecallEntity::getAgentId, agentId)
                    .eq(MemoryRecallEntity::getFilename, uniqueKey)
                    .eq(MemoryRecallEntity::getDeleted, 0)
                    .last("LIMIT 1"));

    LocalDateTime now = LocalDateTime.now();

    if (existing != null) {
        existing.setRecallCount(existing.getRecallCount() + 1);
        existing.setDailyCount(existing.getDailyCount() + 1);
        existing.setLastRecalledAt(now);
        existing.setSnippetPreview(preview);
        
        // 存储关联的 pageId 和原始文件名
        existing.setMetadata(toJson(Map.of(
                "pageId", pageId,
                "filename", filename,
                "chunkId", chunkId
        )));

        if (userQueryHash != null) {
            List<String> hashes = parseQueryHashes(existing.getQueryHashes());
            if (!hashes.contains(userQueryHash) && hashes.size() < MAX_QUERY_HASHES) {
                hashes.add(userQueryHash);
            }
            existing.setQueryHashes(toJson(hashes));
        }

        recallMapper.updateById(existing);
    } else {
        MemoryRecallEntity entity = new MemoryRecallEntity();
        entity.setAgentId(agentId);
        entity.setFilename(uniqueKey);
        entity.setSnippetPreview(preview);
        entity.setMetadata(toJson(Map.of(
                "pageId", pageId,
                "filename", filename,
                "chunkId", chunkId
        )));
        entity.setRecallCount(1);
        entity.setDailyCount(1);
        entity.setLastRecalledAt(now);
        entity.setPromoted(false);
        entity.setScore(0.0);
        entity.setCreateTime(now);
        entity.setUpdateTime(now);
        entity.setDeleted(0);

        if (userQueryHash != null) {
            entity.setQueryHashes(toJson(List.of(userQueryHash)));
        }

        try {
            recallMapper.insert(entity);
        } catch (org.springframework.dao.DuplicateKeyException e) {
            // 并发插入冲突处理
        }
    }
}
```

```java
// 文件: MemoryRecallService.java

public List<MemoryRecallEntity> computeScores(Long agentId) {
    List<MemoryRecallEntity> candidates = listCandidates(agentId);
    
    // 按文件分组，合并同一文件的高评分 Chunk
    Map<String, List<MemoryRecallEntity>> groupedByFile = candidates.stream()
            .filter(c -> c.getFilename().startsWith("chunk:"))
            .collect(Collectors.groupingBy(c -> {
                Map<String, Object> meta = parseMetadata(c.getMetadata());
                return meta != null ? meta.get("filename").toString() : c.getFilename();
            }));
    
    // 对每个文件的 Chunk 评分进行聚合
    List<MemoryRecallEntity> aggregated = new ArrayList<>();
    for (var entry : groupedByFile.entrySet()) {
        List<MemoryRecallEntity> chunks = entry.getValue();
        
        // 计算文件级别的综合评分
        double avgScore = chunks.stream()
                .mapToDouble(MemoryRecallEntity::getScore)
                .average().orElse(0);
        
        // 找出评分最高的 Chunk 作为代表
        MemoryRecallEntity topChunk = chunks.stream()
                .max(Comparator.comparingDouble(MemoryRecallEntity::getScore))
                .orElse(null);
        
        if (topChunk != null) {
            MemoryRecallEntity fileLevel = new MemoryRecallEntity();
            fileLevel.setAgentId(agentId);
            fileLevel.setFilename(entry.getKey());
            fileLevel.setScore(avgScore);
            fileLevel.setRecallCount((int) chunks.stream()
                    .mapToInt(MemoryRecallEntity::getRecallCount).sum());
            aggregated.add(fileLevel);
        }
    }
    
    return aggregated;
}
```

## 十六、总结

本方案完整实现了 **Elasticsearch 全文索引 + Milvus 混合检索** 的双知识库架构，并优化了长期记忆形成机制：

1. ✅ **统一 VectorStore 抽象层**：基于 Java SPI 实现向量数据库解耦与可插拔扩展
2. ✅ **文档 Chunk 切片**：支持句子切分、段落切分、固定长度切分三种策略，保证语义完整性
3. ✅ **Elasticsearch 全文检索**：基于 BM25 算法，支持中文 IK 分词
4. ✅ **Milvus 混合检索**：基于 HNSW 索引，支持余弦相似度语义检索
5. ✅ **RRF 融合排序**：融合全文检索与混合检索结果，提升召回率
6. ✅ **多租户隔离**：通过 workspaceId 分片实现租户隔离，独立 Index/Collection
7. ✅ **容错降级机制**：ES/Milvus 并行检索，任一失败自动降级，两者都失败则降级到 MySQL
8. ✅ **异步 Embedding 流水线**：@Async + CompletableFuture + 线程池实现非阻塞向量化存储
9. ✅ **数据一致性保障**：Spring 事务 + Retry 重试 + 补偿任务调度
10. ✅ **MCP 集成**：封装为知识检索工具供 Agent 调用，实现长期记忆与自主工具调用
11. ✅ **Chunk 级长期记忆**：细化召回频率统计粒度，精准识别有价值的知识片段

此架构全面解决了 RAG 场景下的核心问题，为构建强大的企业级知识库系统奠定了坚实基础。
